## 详细验证

### Bug #1: 无向导 → 已修复

**问题**: 安装时没有向导界面，直接静默安装。
**修复**: electron-builder.yml 配置 `win.target: nsis`，NSIS 安装器默认提供向导 UI。
**代码证据**: `client/electron-builder.yml` 第 14-16 行
```yaml
win:
  target:
    - target: nsis
```

### Bug #2: 装错目录 → 已修复

**问题**: 安装目录名为 `client` 而非 `TidalFlow`。
**修复**: electron-builder.yml 设置 `productName: TidalFlow`，NSIS 使用 productName 作为默认安装目录名。
**代码证据**: `client/electron-builder.yml` 第 2 行
```yaml
productName: TidalFlow
```

### Bug #3: 无窗口 → 已修复

**问题**: 启动后没有窗口出现。
**修复**: `main/index.ts` 中 `createMainWindow()` 创建 BrowserWindow，`ready-to-show` 事件触发 `win.show()`。
**代码证据**: `client/src/main/index.ts` 第 18-55 行
- `new BrowserWindow({...})` 创建窗口
- `win.once('ready-to-show', () => { win.show(); })` 确保窗口显示

### Bug #4: 无托盘 → 已修复

**问题**: 系统托盘没有 TidalFlow 图标。
**修复**: `tray.ts` 实现完整的托盘功能，包括图标、右键菜单、点击切换面板。
**代码证据**: `client/src/main/tray.ts`
- `createTray()` 创建托盘图标 (第 93-113 行)
- 右键菜单: 显示面板、设置、开机自启、退出 (第 30-62 行)
- 点击事件: `togglePanelWindow()` (第 111-113 行)

### Bug #5: 僵尸进程 → 已修复

**问题**: 关闭窗口后进程仍在运行。
**修复**: 
1. 窗口关闭事件 (`close`) 设置 `event.preventDefault()` + `win.hide()` 实现最小化到托盘
2. 退出菜单调用 `app.quit()` 真正退出
3. `will-quit` 事件中调用 `destroyPanelWindow()` 和 `destroyTray()` 清理资源
**代码证据**: 
- `client/src/main/index.ts` 第 47-51 行: close 事件处理
- `client/src/main/index.ts` 第 108-110 行: will-quit 清理
- `client/src/main/tray.ts` 第 61 行: 退出菜单调用 `app.quit()`

### Bug #6: 卸载残留 → 已修复

**问题**: 卸载后安装目录未完全删除。
**修复**: commit 8e67a15 "fix: uninstaller kills app process before removing files" 确保卸载前终止进程。
**代码证据**: git log 确认修复已合入 develop 分支。
