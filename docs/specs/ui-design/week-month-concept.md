# TidalFlow UI — 周视图 & 月视图 设计概念

> 2026-06-24 · 与 PO 讨论确定 · 等 Phase 2-3 功能需求明确后再出 image2 设计图

---

## 设计原则

日/周/月三层视图同属一套设计语言（宇宙深蓝基底 / 琥珀暖光 / 青蓝微光 / 薄荷绿冷光 / 珊瑚色过载警告），不因视图切换改变视觉基调。

---

## 周视图

### 布局

横向七列（周一至周日），每列是当天的"缩略版潮间带"。

### 视觉元素

- 每列顶部显示日期和星期
- 列内：小光点表示任务，光点大小 = 任务时长，光点颜色：
  - 琥珀色 = 待完成
  - 薄荷绿 = 已完成
- 任务密集的列（≥5个任务）光点排列紧密 —— 对应"大潮日"
- 任务稀疏的列（≤2个任务）留白多 —— 对应"小潮日"
- 今天的列有微弱的琥珀色柔光边框

### 交互

点击任意一天 → 展开为该天的凝望态日视图（图1）

## 月视图

### 布局

标准月历网格（7列 × 5-6行）。

### 视觉元素

每格显示月相图标，映射该天完成度：

| 图标 | 含义 |
|------|------|
| 🌕 满月 | 全天任务全部完成 |
| 🌗 半月 | 部分完成 |
| 🌑 新月 | 当天无任务 或 全部未完成 |
| 🔴 血月 | 任务过载 / 超时（暖珊瑚色，不是红色） |

今天的格子有微弱琥珀色柔光边框。

### 交互

点击任意一天 → 展开为该天的凝望态日视图（图1）

### 底部图例

``` 
🌕 全部完成  🌗 部分完成  🌑 未完成  🔴 过载
```

## 三层下钻关系

```
月视图（月相概览）
  ↓ 点击某天
周视图（七天缩略）
  ↓ 点击某天
日视图（凝望态 —— 图1 主视图）
```

与主流日历应用一致，交互学习成本为零。

## 扩展时机

| Phase | 可能引入的视图 | 触发条件 |
|-------|-------------|---------|
| Phase 2 | 周视图 | 工时记录上线后，用户需要回顾本周活动分布 |
| Phase 3 | 月视图 | 复盘摘要 + 成就感可视化需要月度概览 |
| Phase 4 | 月视图完善 | 个性化参数调优需要更长时间尺度数据 |
